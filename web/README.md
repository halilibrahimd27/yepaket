# YePaket Web

YePaket'in responsive tanıtım sitesi ve dummy MyStore işletme paneli.

## Kapsam

- Responsive landing, paket keşfi ve detay modalı
- İşletme çözümü, gelir hesaplayıcı ve başvuru formu
- MyStore dummy giriş ve yönetim paneli
- Paket, sipariş, gelir ve mağaza yönetimi
- Yardım merkezi ve destek formu
- GSAP giriş/scroll animasyonları
- Tailwind CSS v4 tasarım sistemi
- Ortak API base URL ve backend sözleşmesi

## Çalıştırma

```bash
npm install
npm run dev
```

Demo giriş: `demo@modafirini.com` / `demo1234`.

API modunu değiştirmek için `.env.example` dosyasını `.env.local` olarak
kopyalayın. Backend sözleşmesi [`../docs/API_CONTRACT.md`](../docs/API_CONTRACT.md)
dosyasındadır.
